# Contributing

Pull requests are welcome. Please read these guidelines before submitting one.

## Guidelines

* One pull request per suggestion.
* Add the entry to the most fitting section, in alphabetical order.
* Use the format `* [Name](link) - Short description`.
* Check that the link works and that the resource isn't already listed.
* Keep the description short and neutral: say what it is, not why it's the best.

## What we don't accept

* **Self-promotion.** We don't accept pull requests that add your own website, product or service. The list is meant to collect resources the community actually uses, not to be a place for backlinks. Open-source fonts, tools and datasets you created are an exception: they're welcome if they have a public repository and an open license.
* **Unicode "fancy text" generators.** Tools that turn text into Unicode look-alike characters (cursive, bold, "cute" fonts for social media bios) aren't fonts and are out of scope.
* **Font download aggregators** whose catalogs mix free and commercial fonts or don't make each font's license clear.
* **Duplicates** of entries already in the list.

Pull requests that break these rules will be closed without further discussion.
